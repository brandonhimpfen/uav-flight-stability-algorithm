# Roadmap

## Version 1.0.0

Initial explainable algorithm release.

Included:

- telemetry CSV analysis
- four component scores
- adaptive context weighting
- exponential smoothing
- severity levels
- reason codes
- JSON and CSV reporting
- documentation and examples

## Possible version 1.1

- additional sample logs
- configurable YAML settings
- chart generation
- richer command-line output
- schema validation command
- more complete anomaly injection utilities

## Possible version 1.2

- aircraft profiles
- payload profiles
- environment profiles
- baseline comparison against known normal flights
- batch analysis of multiple logs

## Possible version 2.0

- machine-learned baseline calibration
- labelled anomaly classification
- adaptive threshold learning
- aircraft-specific anomaly models
- dashboard or web interface
- integration with common autopilot log formats

## Research opportunities

This project could support a short technical paper covering:

- adaptive anomaly scoring for UAV telemetry
- limitations of static threshold systems
- explainable multi-signal flight stability scoring
- synthetic anomaly evaluation
- future use of lightweight ML for aircraft-specific baselines
